# Full audit — August 2026

Nine specialist agents audited the extension after the trim that removed roughly a third of
its surface. This is the complete record: what was found, what was fixed, and what was
deliberately not.

**Why it was worth doing:** the suite was green at 413 tests and ~95% coverage before this,
and the audit still found a control that keyboard users could not reach at all. A green suite
proves nothing was broken by a change; it says nothing about what was never covered.

Two findings were reported independently by two agents each — the models-bridge reply gap
(security + typescript) and the tab keyboard trap (a11y + tests). Agreement across separate
remits is the strongest signal in a report like this.

## Fixed

Every item below is covered by a test. Where the behaviour is focus, layout or sizing, that
test is in `tests/e2e/` — jsdom only pretends to have those.

## Not fixed, and why

These are real. They are recorded rather than done because each changes behaviour or costs
more than this pass allowed.

| Severity | Finding                                                                                                                                                                                                                                                     | Why deferred                                                                                                                                                                                                                           |
| -------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| HIGH     | **Truncation is never surfaced.** No parser checks `finish_reason: length` or `stop_reason: max_tokens`, and Gemini's extractor explicitly whitelists `MAX_TOKENS`. A rewrite cut off by the token limit is presented as complete — mid-sentence, silently. | A behaviour change needing a product decision: surface it as an error and lose the partial text, or as a notice alongside it. The latter needs a UI affordance that does not exist yet.                                                |
| HIGH     | **`loadSettings` heals wholesale.** One corrupt field discards the entire object, **including the API key**, with only a console warning.                                                                                                                   | The fix — per-field healing plus telling the user their key was dropped — is a real behaviour change. Mitigated today: stored values merge over defaults first, so a _missing_ field is harmless; only genuine corruption triggers it. |
| MEDIUM   | **A missing field is read as an empty one** at the non-streaming call sites, so an API shape change or a model refusal becomes a successful empty rewrite.                                                                                                  | Behaviour change; needs to distinguish "key absent" from "key empty" per provider.                                                                                                                                                     |
| MEDIUM   | **PING resolves on the first frame to answer, not the target frame.** On a multi-frame page the shortcut can be delivered before the frame holding the selection is listening.                                                                              | Pre-existing and architectural. Its blast radius grew when the frame-scoped context-menu path was removed, but the fix is a redesign of the readiness handshake.                                                                       |
| MEDIUM   | **`SelectionInfo` is an undiscriminated union.** Correlated fields (a range versus offsets) are enforced only by its two constructors, and `replace.ts` recovers the correlation with a cast.                                                               | Worth doing, no live bug behind it. Roughly four source files and three test files; typecheck finds every site. The cheap slice — deleting the unused `element` on the rich-text path — is the part to do first.                       |
| MEDIUM   | **The API key travels to any https base URL**, for every provider, not just `custom`.                                                                                                                                                                       | Not a schema fix: `custom` legitimately needs arbitrary hosts. Wants an advisory warning in the options UI when a base URL is set on a provider that does not need one.                                                                |
| LOW      | No sender check on the bridges, so `LIST_MODELS` is reachable from a content script. **Not currently exploitable** — nothing gives a page a route into the isolated world.                                                                                  | Defense in depth; one line, but worth doing deliberately rather than as audit cleanup.                                                                                                                                                 |
| LOW      | `--border-strong` is 2.00:1 against the light surface, under the 3:1 for non-text.                                                                                                                                                                          | Mitigated: the buttons it outlines carry legible labels, so they stay identifiable. A palette change deserves its own pass.                                                                                                            |
| LOW      | `stripWrappingQuotes` can strip quotes that were the model's intended content.                                                                                                                                                                              | The file already documents this class of tradeoff for preamble stripping; this one now matches it.                                                                                                                                     |
| LOW      | `nextFrame()` never settles in a hidden tab, stranding the replace re-entry guard.                                                                                                                                                                          | Needs a race with a timeout; narrow window, never reported.                                                                                                                                                                            |

## Rejected

- **`refactor-cleaner` found no dead code.** Verified: every CSS class, export, dependency and
  test helper it checked is referenced. The trim cleaned up after itself.
- **Renaming the `copied-dirty` outcome.** The name is awkward, its comment disambiguates it,
  and a rename costs a literal plus its consumer for no behavioural gain. Opportunistic at best.
- **Splitting `ReplaceOutcome` into an outcome plus a `pageDirty` flag.** Only one variant needs
  the extra bit; a flag re-introduces the "which combinations are valid" question that the flat
  union exists to avoid.

## What the imports were worth

`a11y-architect` and `wcag-audit-patterns` earned their place — three CRITICAL findings and all
the contrast arithmetic came from them, in an area `known-issues.md` had already admitted was
unexamined.

`performance-optimizer` was imported and **not run**. The first two waves filled the available
budget, and its remit — content-script weight, render behaviour during streaming — had no
reported symptom behind it. It stays in `.claude/agents/` for a pass that has one.

## How the audit was run, for next time

The first attempt launched eleven agents at once, each told to audit the extension, and
exhausted the session limit — three burned about 100k tokens apiece before dying. What worked
was scoping each agent to five or so named files, matching the model to the work (opus for the
adversarial and async reasoning, sonnet for the criteria-driven passes, haiku for the
grep-and-verify sweeps), and running in waves of three. The same nine agents then averaged
under fifteen tool calls each.
